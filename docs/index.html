WHEN THE DOWNLOAD IS READY

Drag. Open. Allow.

  1. Open the DMG and drag AutoType to Applications.
  2. Allow AutoType in System Settings → Privacy & Security → Accessibility.
  3. Enter your text, click Send text, and focus your destination.
A note on compatibility. AutoType sends keyboard events; it does not invoke clipboard paste. Instant mode is experimental, and receiving apps may change or reject input. Indentation correction requires the macOS Command-Shift-Left shortcut. Start on an empty line when using it.
